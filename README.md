# Pass the Atlas

A local party game: friends take turns **doodling a map**, then **stamp it with creatures, traps, and treasure**, then **play the world they made**.

Open `index.html` in a browser (or run a tiny static server). One keyboard, one table, several pencils.

## How a session works

1. **Gather** — 1–4 cartographers, each with a name and an ink colour.
2. **Chapter I · Land** — take turns painting terrain (grass, water, lava, ice, pits…).
3. **Chapter II · Fixtures** — walls, doors, bridges, chests, campfires, portals, bounce pads.
4. **Chapter III · Life** — slimes, bats, knights, mimics, coins, keys, hearts, spikes.
5. **Play** — drop into the doodle as a stick-hero. Reach an exit. Try not to get eaten by your friends’ ideas.

Each turn you get a limited **ink budget**. When you are done (or dry), **pass the pencil**.

## Controls

**Editor**
- Left drag: stamp / paint
- Right drag or `E`: eraser
- `1–9`: jump the palette
- `Z` / `Ctrl+Z`: undo this turn
- Mouse wheel: zoom · middle-drag or `Space`-drag: pan
- `G`: toggle grid

**Adventure**
- `WASD` / arrows: walk
- `J` / click: scribble-slash
- `K` / `Shift`: dash
- `E`: open chests, read signs, light campfires
- `P` / `Esc`: pause

## Modes

- **Relay** — one shared expedition. Die and the next friend continues from the last campfire.
- **Gauntlet** — everyone runs the same atlas. Best score on the corkboard wins.

## References that shaped it

- Super Mario Maker — editor and play share one world
- The Quiet Year / Dawn of Worlds — take turns drawing a place
- Paper Mario, Doodle Jump, Sketchbook UI, Rough.js — paper, ink, wobble
- Jackbox / hot-seat party games — pass the machine, big interstitial
